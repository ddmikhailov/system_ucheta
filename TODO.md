## 5. 🔵 Технический долг

- [ ] **N+1 запросы** (замерено на тестовом наборе, 989 студентов):

      | Экран | SQL-запросов | Время (SQLite, локально) |
      | --- | --- | --- |
      | Журнал одной группы | 106 | 0.07 с |
      | `/curator/groups` | 107 | 0.11 с |
      | День по колледжу | 177 | 0.21 с |
      | Группа риска | **3959** | **4.6 с** |
      | Excel за 30 дней | 420 | 1.6 с |

      На MySQL по сети будет в разы медленнее. Причина — `consecutive_unexcused_count` на каждого студента и
      `resolve_day_type` на каждый день. Считать пакетно.
- [ ] **Тяжёлая синхронная работа в event loop** — задания планировщика (`scheduler/jobs.py`) и обработчики бота

      запросов). В встроенном режиме это **замораживает весь сайт** на время рассылки. Выносить в
      `asyncio.to_thread`.

      `AbsencePeriodModal`) → общий компонент журнала. `todayIso()` скопирован в 6 файлов. `_scope_department_id` —
