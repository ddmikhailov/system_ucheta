- [x] **N+1 запросы** (замерено на тестовом наборе, 989 студентов) — исправлен худший случай:

      | Экран | SQL-запросов | Время (SQLite, локально) |
      | --- | --- | --- |
      | Журнал одной группы | 106 | 0.07 с |

      «Группа риска» была на два порядка хуже всех остальных экранов — `risk_students` вызывала
      `consecutive_unexcused_count` на каждого из ~1000 студентов колледжа, а та внутри ещё раз шла в БД за

      вызывающим кодом вместо повторного `db.get(Student, ...)`; (2) новая `consecutive_unexcused_counts_bulk`
      группирует студентов по `study_group_id`, считает `study_days_between` один раз на группу и выбирает отметки
      одним запросом на группу (`IN (...)`) вместо одного на студента. Регрессия —
      `test_risk_students_query_count_does_not_scale_with_student_count` (считает реальные SQL через
