# История версий

## 1.3.0 — 2026-09-24

- **Индикатор процента**: сделан тоньше и в цветах платформы вместо сплошной цветной «наклейки».
- **Роль «Тьютор»**: полный доступ по всему колледжу, как у администратора.
- **Смена ролей**: право менять роль пользователю теперь есть только у администратора и у зав. отделением (в границах «куратор ⇄ заместитель ⇄ зав. отделением»); у всех остальных, включая тьютора и воспитательный отдел, доступа к этому нет. Отдельная подпись «Советник директора по воспитанию» для зав. отделением убрана из интерфейса — при редактировании роли выбор больше не предлагается.
- **Мобильная адаптация**: журнал группы у куратора и у администрации на телефоне превращается в карточки по студенту вместо таблицы; увеличены поля/кнопки под палец, поправлены модальные окна и панель уведомлений.
- **Пользователи**: правый блок с множеством кнопок управления убран из таблицы — все действия с пользователем (логин/ФИО, роль, пароль, разблокировка, архив/удаление) теперь открываются по клику на ФИО в отдельном окне профиля; список разбит на страницы.
- **Календарь**: суббота автоматически считается учебным днём только у 1 курса, у остальных курсов — выходной. Добавлен тип дня ЭФО (электронная форма обучения). Появилась возможность задавать исключения календаря отдельно для конкретной группы — приоритетнее общего календаря колледжа.

## 1.1.0 — 2026-09-23

Обновление по итогам первого раунда тестирования.

- **Логины и пароли**: одноразовые пригласительные ссылки убраны из интерфейса. Администратор (по всему колледжу) и зав. отделением (в своём отделении) выдают временный пароль напрямую — сгенерированный или свой; при первом входе человек обязан задать собственный. Разблокировка после неудачных попыток входа — тоже прямо из админки.
- **Полное управление списками**: группы, студенты и кураторы теперь редактируются, архивируются и удаляются на месте. Удаление из архива безопасно — если есть история (посещаемость, назначения), запись либо не удаляется физически (группы), либо обезличивается с сохранением статистики (студенты, пользователи). Куратора можно снять с группы без потери истории назначения.
- **Журнал группы для администрации**: у admin/edu_department — по всему колледжу, у зав. отделением — в своём отделении. Любая группа, любой день, полное право правки, видно, кто и когда внёс каждую отметку.
- **Правки задним числом**: куратор может отредактировать посещаемость за любой прошедший день (было — только вчера). Если правка отстоит от занятия больше чем на 48 часов, зав. отделением получает уведомление.
- **Внутриплатформенные уведомления**: колокольчик в шапке — пока единственный канал, раз Telegram скрыт из интерфейса (сам бот и планировщик остаются на сервере, включаются настройкой).
- **Приказ/справка** у кодов отметок стали необязательным дополнением без контроля дедлайна — экран «Контроль оснований» убран, поле осталось.

## 1.0.0 — 2026-09-23

Первый релиз, развёрнут на тестовом сервере Amvera.

- Журнальная модель посещаемости: куратор отмечает только исключения, «сдача дня» фиксирует остальных присутствующими.
- Роли: куратор, заместитель куратора, заведующий отделением, воспитательный отдел, администратор.
- Витрины: день по колледжу, динамика, группа риска, дисциплина кураторов, контроль оснований, вакантные группы; экспорт в Excel.
- Админ-панель: отделения, группы, студенты, коды отметок, пользователи, учебный календарь; вход кураторов по одноразовым ссылкам-приглашениям.
- Telegram-бот и планировщик напоминаний/дайджестов, встроенные в основной процесс.
- Единое приложение (API + фронтенд + бот + планировщик) в одном Docker-образе, MySQL — отдельно.
- Самостоятельный старт контейнера: ожидание БД, миграции, справочники, импорт выгрузок «Диджитал» из постоянного хранилища.
- Импортированы данные отделения «Диджитал»: 44 группы, 989 студентов, 24 куратора.
