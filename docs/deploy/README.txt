Цифровой куратор (КАИТ №20) — папка deploy

Что здесь лежит (всё, что нужно системному администратору помимо самого приложения из папки backend):

  kait20-instrukciya-administratoru.pdf   пошаговая инструкция по установке и эксплуатации (читать первой)
  kait20-obnovlenie-3.5.1.txt             обновление уже работающей платформы до 3.5.1 (Linux и Windows, проверка, откат)
  kait20-nadezhnost.txt                   сообщения о проблемах, сбор ошибок, проверка /health, резервные копии,
                                          журнал действий: срок хранения (год) и помесячный архив
  kait20-klyuch-dosie.txt                 ключ шифрования досье: где хранить и как сменить без потери данных

  Linux:
    kait20-apache.conf                    виртуальный хост Apache 2.4 (HTTPS, обратный прокси на 127.0.0.1:8000)
    kait20.service                        служба systemd
    kait20-backup.sh                      ежедневная резервная копия БД (запускается из cron)

  Windows:
    kait20-apache-windows.conf            виртуальный хост Apache для Windows
    kait20-service.ps1                    запуск приложения задачей Планировщика заданий
    kait20-backup.ps1                     ежедневная резервная копия БД (Планировщик заданий)

Состав архива:
  backend/   приложение (код, готовый интерфейс в backend/static, миграции БД, скрипты загрузки данных,
             список зависимостей requirements.txt, шаблон настроек .env.example)
  frontend/  исходники интерфейса — на сервере не нужны (Node.js не требуется, интерфейс уже собран)
  deploy/    эта папка

Порядок: новая установка — инструкция (PDF), разделы 3–4; обновление с 3.5.0 — kait20-obnovlenie-3.5.1.txt. Версии Python 3.12 и MySQL 8.1.0 на сервере не обновлять (допустимы и Python 3.13/3.14).
Файлы с реальными ФИО (реестр, списки кураторов) в архив не входят и передаются отдельно.
