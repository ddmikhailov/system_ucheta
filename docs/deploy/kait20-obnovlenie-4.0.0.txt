Цифровой куратор (КАИТ №20) — обновление до версии 4.0.0

Кому: системному администратору сервера колледжа и администратору платформы.
Откуда: с версии 3.6.0. С более ранних версий сначала выполнить памятку kait20-obnovlenie-3.6.0.txt
(шаги «Сразу после обновления» там обязательны), затем эту; миграции применятся сами при запуске.


ЧТО НОВОГО (коротко; подробно — CHANGELOG.md)

Кураторам (новые вкладки группы):
  - «Журналы»: куратор загружает выгрузку электронного журнала (.xlsx, одна дисциплина) и смотрит оценки
    и «н» в платформе. «Н» преподавателя не меняет дневные отметки куратора: расхождения показаны списком.
    Средняя ниже 4 подсвечивается, оценка «2» — задолженность.
  - «Успеваемость»: справочник «дисциплина — преподаватель — телефон» с кнопкой «Позвонить».
  - «Практика»: практика всей группы ставит студентам отметку «р» сама; восполнять её не нужно.
  - «Папка куратора»: все документы по п. 5.1 положения в одном месте, выгрузка одной кнопкой.
    Протоколы общих собраний группы создаются прямо в папке.
  - «План группы» → «Инструктаж по охране труда»: записи инструктажей и бланк с подписями в Word.
  - Карточка студента: «Сообщить заведующему» (срочное сообщение, текст зашифрован), выбор шаблона
    сообщения родителям, новый вид записи «Служба примирения».
  - Соц. паспорт группы: списки на стипендию в Excel и Word.

Руководителям:
  - Витрины: вкладки «Практика» (кто сейчас на практике) и «Карточка куратора» (показатели работы по
    группам; видят администратор, воспитательный отдел, зав. отделением и тьютор).
  - «Журнал группы» → блок «Срочные сообщения»: сообщения кураторов, кнопка «Принято».
  - Задачи → «Шаблоны»: набор «Адаптация первого курса» (шесть задач по неделям для групп 1 курса).
  - Админка → «Назначить куратора»: замена куратора на даты (заместитель с периодом «по дату»);
    уведомление получают и заместитель, и основной куратор.
  - Админка → «Студенты»: список изменений ПДн студентов за месяц (без значений).

Изменения для сервера:
  - Миграции БД: 6 новых, одной цепочкой после r1a2b3c4d5e6:
      a8b9c0d1e2f3  таблицы lesson_marks и journal_lessons (журналы дисциплин)
      b9c0d1e2f3a4  срочные сообщения заведующему
      c0d1e2f3a4b5  safety_instructions (инструктаж по охране труда)
      d1e2f3a4b5c6  group_subjects (дисциплины и преподаватели)
      e2f3a4b5c6d7  group_assemblies (общие собрания группы)
      f3a4b5c6d7e8  практика группы
    Применяются сами при запуске (scripts.entrypoint).
  - Новых Python-пакетов и новых параметров .env нет. pip install на шаге 3 оставлен для проверки:
    он должен закончиться без установки новых пакетов.
  - Модуль journals входит в релизный набор. Если ENABLED_MODULES в .env задан явно, вкладка «Журналы»
    появится только после добавления journals в список.
  - Требования прежние: Python 3.12 (допустимы 3.13/3.14), MySQL 8.1.0+.


ПЕРЕД ОБНОВЛЕНИЕМ

  1. Проверить целостность архива (файл .sha256 лежит рядом с архивом):
       Linux:    sha256sum -c kait20-4.0.0.zip.sha256
       Windows:  Get-FileHash .\kait20-4.0.0.zip -Algorithm SHA256   (сравнить с содержимым .sha256)
  2. Резервная копия БД обязательна: в этой версии есть миграции.
  3. Выбрать время, когда кураторы не отмечают посещаемость: перерыв в работе — 1–2 минуты.
  4. Попросить кураторов сдать начатые дни до обновления.


ОБНОВЛЕНИЕ — LINUX (пути и имена — как в инструкции администратору, раздел 5.4)

  # 1. резервная копия БД и копия текущей версии
  sudo -u kait20 /opt/kait20/kait20-backup.sh
  sudo rm -rf /opt/kait20/backend.prev
  sudo cp -a /opt/kait20/backend /opt/kait20/backend.prev

  # 2. распаковать новую версию
  cd /tmp && sha256sum -c kait20-4.0.0.zip.sha256
  rm -rf /tmp/kait20-new && unzip -q kait20-4.0.0.zip -d /tmp/kait20-new

  # 3. остановить, заменить код (сохранив .env и .venv), проверить зависимости, запустить
  sudo systemctl stop kait20
  sudo rsync -a --exclude .env --exclude .venv /tmp/kait20-new/backend/ /opt/kait20/backend/
  sudo chown -R kait20:kait20 /opt/kait20/backend
  cd /opt/kait20/backend && sudo -u kait20 .venv/bin/pip install --require-hashes -r requirements.txt
  sudo systemctl start kait20

  # 4. проверка
  curl -s http://127.0.0.1:8000/health                 # -> {"status":"ok"}
  grep '^version' /opt/kait20/backend/pyproject.toml   # -> version = "4.0.0"
  journalctl -u kait20 -n 80 --no-pager                # строки "Running upgrade ... -> f3a4b5c6d7e8", без ошибок
  cd /opt/kait20/backend && sudo -u kait20 .venv/bin/alembic current   # -> f3a4b5c6d7e8 (head)


ОБНОВЛЕНИЕ — WINDOWS (инструкция администратору, раздел 10.4)

  # 1. резервная копия БД (задача kait20-backup) и копия текущей версии
  Start-ScheduledTask kait20-backup
  robocopy C:\kait20\backend C:\kait20\backend.prev /MIR /XD .venv

  # 2. распаковать новую версию
  Expand-Archive .\kait20-4.0.0.zip -DestinationPath C:\Temp\kait20-new -Force

  # 3. остановить, заменить код (сохранив .env и .venv), проверить зависимости, запустить
  Stop-ScheduledTask kait20
  robocopy C:\Temp\kait20-new\backend C:\kait20\backend /E /XD .venv /XF .env
  C:\kait20\backend\.venv\Scripts\pip install --require-hashes -r C:\kait20\backend\requirements.txt
  Start-ScheduledTask kait20

  # 4. проверка
  Invoke-WebRequest http://127.0.0.1:8000/health -UseBasicParsing     # -> {"status":"ok"}
  Select-String '^version' C:\kait20\backend\pyproject.toml           # -> version = "4.0.0"
  Get-Content C:\kait20\logs\kait20.log -Tail 80                      # "Running upgrade ... -> f3a4b5c6d7e8", без ошибок
  cd C:\kait20\backend; .venv\Scripts\alembic current                 # -> f3a4b5c6d7e8 (head)


СРАЗУ ПОСЛЕ ОБНОВЛЕНИЯ — АДМИНИСТРАТОРУ ПЛАТФОРМЫ

  1. Если ENABLED_MODULES в .env задан явно — добавить journals (см. выше) и перезапустить службу.
  2. Проверить, что у каждого отделения есть активный заведующий: ему приходят срочные сообщения
     кураторов. Если заведующего и воспитательного отдела в отделении нет — сообщения уходят администраторам.


ЧТО СКАЗАТЬ ПОЛЬЗОВАТЕЛЯМ

  Кураторам: в группе новые вкладки «Журналы», «Успеваемость», «Практика» и «Папка куратора». Выгрузку
  электронного журнала загружайте во вкладку «Журналы» по одной дисциплине. Документы по положению
  забирайте в «Папке куратора». Срочное — кнопкой «Сообщить заведующему» в карточке студента.

  Заведующим отделением и воспитательному отделу: срочные сообщения кураторов — во вкладке «Журнал группы»,
  блок «Срочные сообщения»; карточка работы куратора и практика — в витринах; замена куратора на даты —
  в окне «Назначить куратора».


ПРОВЕРКА В БРАУЗЕРЕ (после обновления)

  1. Войти администратором — рабочий экран открывается.
  2. Открыть любую группу: есть вкладки «Журналы», «Успеваемость», «Практика», «Папка куратора».
  3. «Папка куратора» → скачать табель за текущий месяц (PDF открывается).
  4. Витрины: есть вкладки «Практика» и «Карточка куратора».
  5. Сверху страницы — плашка «Что нового в версии 4.0.0»; в меню под именем — «Версия 4.0.0».


ОТКАТ (если что-то пошло не так)

  В 4.0.0 есть миграции, поэтому сначала откатить схему БД НОВЫМ кодом (в старом нет файлов миграций),
  потом вернуть прежнюю папку. Данные, введённые после обновления в новые таблицы (журналы дисциплин,
  преподаватели, практика, инструктажи, общие собрания, срочные сообщения), при откате пропадут.

    Linux:    sudo systemctl stop kait20
              cd /opt/kait20/backend && sudo -u kait20 .venv/bin/alembic downgrade r1a2b3c4d5e6
              sudo rsync -a --delete --exclude .env --exclude .venv /opt/kait20/backend.prev/ /opt/kait20/backend/
              sudo systemctl start kait20
    Windows:  Stop-ScheduledTask kait20
              cd C:\kait20\backend; .venv\Scripts\alembic downgrade r1a2b3c4d5e6
              robocopy C:\kait20\backend.prev C:\kait20\backend /MIR /XD .venv /XF .env
              Start-ScheduledTask kait20

  Если alembic downgrade завершился ошибкой — восстановить БД из резервной копии, сделанной на шаге 1,
  и вернуть прежнюю папку.
