# Данные для импорта

`groups.csv`, `curators.csv`, `students.csv` сюда **не входят в git** —
репозиторий публичный, а в этих файлах реальные ФИО студентов и кураторов
«Диджитал» (groups.csv тоже — там есть колонка с ФИО куратора).

Файлы нужно положить в эту папку вручную (например, `scp` на сервер или
скопировать в контейнер) перед запуском:

```bash
python -m scripts.seed
python -m scripts.import_source_data
```

Формат каждого файла и логика извлечения — см. `README.md` в корне проекта,
раздел «Импорт данных «Диджитал»».
